Core — both readers use the same explicit source, so disagreement is real drift Advisory — both answers are defensible but shaped differently
Scored flat across all fields this sample reads 0.76, which looks like a failing extractor. It is not. category_path and option_values sit at zero because the deterministic reader copies the site's breadcrumb and raw option encoding verbatim while the LLM infers its own granularity and reshapes options into semantic keys. Both readings are defensible, so comparing them by equality measures formatting rather than correctness. Only the core score is compared to the threshold, so a representation difference can neither manufacture nor mask an alert.

This is consistency, not accuracy — both extractors can agree and both be wrong. Real accuracy needs labelled samples or a trusted reference feed.
